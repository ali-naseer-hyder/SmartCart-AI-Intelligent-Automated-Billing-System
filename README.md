🛒 SmartCart AI: Real-Time Edge-Based Retail AutomationProject OverviewSmartCart AI is a next-generation intelligent billing solution designed to bridge the gap between traditional retail and fully autonomous shopping experiences. By leveraging Computer Vision and Deep Learning, the system transforms a standard checkout counter into an automated station capable of identifying products and generating bills in real-time without manual barcode scanning.The core of the project is built on the YOLOv8 (You Only Look Once) architecture, specifically optimized for high-frame-rate performance on edge devices. The system doesn't just "see" items; it tracks them uniquely, ensuring that each product is billed only once as it passes through the detection zone.Technical ArchitectureThe project follows a modern decoupled architecture, separating the heavy-lifting AI backend from the user-facing interface:Backend (Python/Flask): Acts as the central controller. It manages the hardware camera stream, processes frames through the Neural Network, and maintains the "Cart State." It utilizes a Temporal Filtering Algorithm—a custom logic layer that implements a cooldown period for object IDs to prevent redundant billing.Frontend (HTML5/CSS3/JS): A custom-designed dashboard that communicates with the Flask server via asynchronous API calls. It provides a live visual feed with bounding-box overlays and a dynamic billing table that updates instantly as items are detected.The Model: While initialized with COCO weights, the system is designed to be fine-tuned via Transfer Learning on specific retail datasets, allowing it to recognize brand-specific packaging with high precision.Key FeaturesReal-Time Tracking: Uses the BoT-SORT/ByteTrack algorithm to maintain item identity across frames.Autonomous Billing: Instant price look-up from a localized database upon successful object verification.Responsive UI: A sleek, dark-themed dashboard optimized for retail kiosks.Edge-Ready: Small model footprint ($YOLOv8n$) allows for deployment on standard laptop hardware without the need for expensive dedicated GPUs.This project serves as a Proof of Concept (PoC) for the future of "Grab and Go" retail technology, emphasizing speed, accuracy, and user experience.
